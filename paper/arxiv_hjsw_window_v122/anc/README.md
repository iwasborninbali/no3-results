# HJSW window v1.22 ancillary evidence

The evidence of record is this directory. Source scripts and historical data were copied from saturation commit `0ce39b4eff374186036a677dab3baa7ace43f4ae`. `SOURCE.json` records the original SHA-256 of every copied source/data file and each adaptation. `upstream/` retains archival text for adapted scripts, with local path spellings normalized in v1.22 as recorded in `SOURCE.json`. No network, solver installation, or source-repository modification was used.

Selected historical HJSW logs, JSON solver reports, mathematical supporting notes, and NPZ line dumps retain their numerical content; portable path substitutions in 16 inherited text files are explicitly recorded with before/after hashes in `SOURCE.json`. Unrelated correspondence and exploratory files are omitted. They are archival evidence, not new exact certificates. Some historical notes contain stronger claims or refer to unbundled exploratory programs: the v1.22 TeX governs mathematical status: PC, BT and CP under its structural hypotheses are proved, as is a weaker UM. Original UM, 2.652, G3 and BS remain open. Only the active scripts listed below are entry points of this bundle. All their repository-local imports are included.

`independent/check.py` and `independent/constants.py` are programs supplied with the first v1.19 audit (R1, by an OpenAI GPT-6 agent), adapted for local paths and to omit the old repository/archive identity check. `independent/model_arithmetic.py` is the side-effect-free integration portion. The active `slack/pp_constant_exact.py` calls that exact rational integrator because SymPy is absent offline; the original SymPy source is retained as text. The four integration regions and mathematical output are unchanged. `verify_v120.py` retains its exact checks of the v1.20 formulas and the p=5 cubic exception. `verify_v121.py` independently checks the larger-window counterexample and containing-window witnesses, the cubic exceptional-fibre corrections, and the closure and seven-group signs; it imports no earlier verification code and needs only the standard library. The v1.21 corrections follow three reads of v1.20, including a clean-context read, and an editorial residual from a returning reviewer.

`verify_v122.py` independently checks the weak-margin constants, CP sieve and partner laws through degree 15, BT arithmetic and the repaired block verifier, including the fractional-index negative test. The new `bs_search/` directory contains exact finite certificates through p=503; BS remains open. Its verifier needs only the standard library. The new proofs were read by a returning reviewer, a clean-context read and a scripted read.

The other audits were the second v1.19 audit (R2, by an OpenAI GPT-6 agent) and the third v1.19 audit (R3, a scripted check by a Claude Opus 5.5 agent).

## Running

Run from this `anc/` directory. The recorded interpreter is "python3 (3.14, with numpy)" (CPython 3.14.6, NumPy 2.5.2, SciPy 1.18.0). Requirements are in `requirements.txt`; `python-sat` is optional only for the explicitly marked jobs. No package was downloaded. SciPy LP/MILP uses HiGHS with the source settings; a successful process or floating objective is not an exact certificate.

```sh
python3 run_all.py
```

`run_all.py` is the batch driver (three independent subprocesses; `OMP_NUM_THREADS=1`, `OPENBLAS_NUM_THREADS=1`). It invokes `run_one.py` for each job in `jobs.json`. Every `.py` file in the bundle is either one of these two executed drivers or has a listed job. The recorded v1.22 command was `python3 run_all.py`: all 45 jobs were processed, with 43 PASS, two NOT RUN and zero failures. `python3 -B verify_v122.py` and `python3 -B bs_search/search_blocks.py --verify` also passed directly. The v1.20 and v1.21 verification programs are unchanged.

`run_one.py` puts anc and the bundled module directories on `sys.path`, supplies the explicit arguments below, and redirects all Python file writes under `runs/generated/JOB/`. This preserves the committed model table and historical logs. It refuses writes outside anc. Scripts with a bounded function-based rerun are loaded without their historical main routine; the exact invocation is shown below and in `jobs.json`. Bytecode writing is disabled. The expected output column is an excerpt from the recorded run, not a substitute for mathematical assertions.

For a single job use its exact command below. For example the previously silent programs receive real arguments: `potential` supplies p,k pairs to `exact_c.py`; `arcs` supplies the listed primes to `arc_imbalance.py`; `cycle` supplies `199 3` to `cyc_model.py`.

## Integrity

`RUNS.md` records actual commands, exit codes, elapsed seconds and key lines; raw stdout/stderr is under `runs/`. `SOURCE.json` distinguishes copied data from adaptations. `MANIFEST.sha256` covers every file in anc except itself (a self-digest would be circular). Verify from anc with:

```sh
shasum -a 256 -c MANIFEST.sha256
```

Rerunning writes new run records and generated output. Regenerate the manifest after a deliberate new run if you wish to bind that new evidence. The submitted manifest binds the recorded v1.22 runs. Original source digests remain in `SOURCE.json`; local path spellings in archival text were normalized for portability and their before/after hashes recorded.
